# Beemomo

給小朋友的英文練習小站。

## 英文代名詞大冒險：I my mine

看圖片、選答案、聽句子，練習主詞、所有格和所有格代名詞。點表格裡的單字會播放自然的英文發音，也可以玩 16 題看圖選擇，或把代名詞表格填完再對答案。答錯時會有專屬說明，成績頁可以只再練錯題。

- 遊戲資料夾：[pronoun-adventure/](pronoun-adventure/)
- 用瀏覽器打開 [pronoun-adventure/index.html](pronoun-adventure/index.html) 就能玩，不需要安裝或建置。
- 網站首頁 [index.html](index.html) 會進入同一個遊戲。
